# 🚀 Streamlit Application Development

A complete collection of projects and concepts to learn and build **real-world web applications using Streamlit**.

This repository covers **basic → advanced Streamlit development**, focusing on practical applications like dashboards, data tools, and interactive apps.

---

## 📌 About This Repository

This project is designed to:

- Teach Streamlit step-by-step
- Build real-world applications
- Strengthen practical development skills
- Create portfolio-ready projects

---

## 🧠 Topics Covered

- Streamlit Basics
- User Inputs & Interaction
- Data Handling with pandas
- Data Visualization
- Dashboard Design
- Forms & Workflows
- Session State (State Management)
- API Integration
- Multi-Page Applications
- Performance Optimization (Caching)
- Deployment (Cloud Apps)

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/monjurBakthMazumder/Streamlit-Application-Development.git
cd Streamlit-Application-Development
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run a Project

Example:

```bash
cd Day 1 — Setup + First App
streamlit run app.py
```

---

## 🌍 Deployment

You can deploy apps using:

- Streamlit Cloud
- Render
- VPS
